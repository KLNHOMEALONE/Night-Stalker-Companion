# Порт интерфейса в MAUI (NightStalkerCompanion)

Снимок на 22.11, поздний вечер. Принятый макет — `ui/prototype/index.html`, его не трогаем.

## Собрано

Проект: `NightStalkerCompanion/NightStalkerCompanion`, только `net10.0-ios`
(Android на этой машине недоступен: нет SDK, Java 11 вместо 17).
`ProjectReference` на `PardApi.Client/PardApi`. MVVM через `CommunityToolkit.Mvvm` 8.4.2.

Сборка и проверка на симуляторе:

    export DOTNET_ROOT=$HOME/.dotnet
    export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
    ~/.dotnet/dotnet build -f net10.0-ios -r iossimulator-arm64
    # iPhone 18 Pro / iOS 27.2, UDID 9C76ECD5-941A-4EA9-B80D-FA5CFE700852

Слои:

- `Services/` — весь разговор с прицелом: `IPardService` / `PardService` (6018, 6019,
  6001, 6009, 3014 внутри, наружу — снимок состояния и вердикт записи),
  `SampleScope` (профиль 22.11 вместо живого опроса), `Units`, `BallisticsCalculator`,
  `ReticleInfo`.
- `ViewModels/` — `AppState` (один общий снимок на все экраны, singleton) и по вью-модели
  на экран.
- `Controls/` — `StatusStrip` (приборная строка), `WriteBar` (строка состояния записи),
  `AlertCard`.
- `Views/` — экраны макета.

## Что уже ведёт себя честно

- Прибора нет на связи → экран тут же (1.2 с, а не пять таймаутов) переходит на
  сохранённый профиль и показывает амбер-строку «СНИМОК 22.11 19:33 — прибор не
  подключён». Без этой строки снимок неотличим от правды, поэтому она на каждом экране.
- Ни одна запись не называется успешной по ответу прибора: после записи группа
  перечитывается до трёх раз с шагом 1.5 с, вердикт «не применилось» имеет право быть
  только после трёх.
- Заряд — прочерк: команды под строку Battery Life не проверяли.
- Дистанция и снос в живом виде — прочерк: команды прочитать нет, есть только
  `Static_Distance…` в OSD видеопотока.

## Что не сделано

1. Живая картинка: RTSP/H.264 в приложении не читаем (есть `tools/extract_rtp.py`).
2. Список медиа: по Wi-Fi 9—20 с на перечисление, не подключено; быстрее картридер.
3. Экран «Группы A–E» и просмотр ролика — свёрстаны в макете, в приложении их нет.
4. Команда `table_data` / `mem_table` (таблица поправок самого прицела) не перехвачена —
   пока снос считает приложение.

## Три вопроса, которые решает владелец, а не код

1. Строка «Калькулятор» на экране «Баллистика»: в профиле 12 полей, команды под неё нет.
   Сейчас показывается прочерк и подпись «нет команды». Оставлять строку?
2. Таблица сноса — модель «вакуум + угол пристрелки», без сопротивления воздуха; на
   250 м занижает примерно вдвое и с прицелом не сверена. Годится как временная, или
   до перехвата `table_data` её не показывать вовсе?
3. `Color=0` → красный, `Color=1` → белый взято из макета; картинки марок —
   обесцвеченные маски, проверить по ним нельзя. Нужна сверка с живым прицелом.
